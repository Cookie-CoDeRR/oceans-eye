Ocean Data Catalog
Scientific datasets and standardized marine data used by Ocean's Eye. Everything is fetched live from the named public service - no ingestion pipeline, no database; the server keeps only a short-lived in-memory cache (5 minutes, max 100 responses) so repeat questions answer quickly, and nothing survives a restart.
Observation records show where life was reported, not where it is absent or abundant. Temperature: NASA JPL MUR Level-4 satellite SST analysis via NOAA ERDDAP. Trends use ~30-day samples with the seasonal cycle removed; significance is indicative, not proof. Built with AI assistance (disclosed).
